# Sanctuary 🌿

A private, compassionate support tool for genetic science researchers working with animal models. 

This app provides:
- 💚 Emotional validation and coping strategies
- 📿 Faith-based perspectives and prayers
- 🧭 Ethical framework reminders
- 📝 Private journaling space
- 🫁 Guided breathing exercises
- ⚡ Quick support for difficult moments

All data is stored locally on your device. Nothing is ever sent to any server. This is your private space for reflection and support.

Built with love for a friend doing important, difficult work. 💝
